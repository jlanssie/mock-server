# Mock Server

A Node.js application to simulate local endpoints.

## Installation

Use JavaScript Package Manager [npm](https://www.npmjs.com/) to install Mock Server.

```bash
npm install
```

## Usage

Use JavaScript Package Manager [npm](https://www.npmjs.com/) to run Mock Server.

```shell
npm run start
```

## Configuration

Adapt the configuration files to your needs:

- config/routes.json : set endpoints for get, post, put and delete requests.
